TYPE
IBM Plex Sans for UI copy, IBM Plex Mono for every identifier — paths, GUIDs, ref kinds, counts. Nothing below 9.5px, and mono is always ≥10px.
COLOR RULE
Every asset type is one hue at fixed chroma/lightness — so the legend, node dots, table rows and edges all agree, and no type reads louder than another.
EDGES
Edges inherit the source node's hue at low alpha; width encodes the collapsed count. On a trace, off-path elements drop to 12% rather than disappearing.
SCALE
Node budget is a setting (50–5 000, ranked by degree), with folder collapsing and builtin hiding as separate switches. Above budget, the canvas aggregates by folder.
